# Personal Portfolio Website

A simple and responsive personal portfolio website built using **HTML and CSS**. This project showcases my profile, skills, projects, and basic information in a clean and user-friendly layout.

## 🚀 Features

* Responsive portfolio layout
* About Me section
* My Interests section
* Projects section
* Contact page
* Clean and simple UI
* Built with pure HTML and CSS

## 🛠️ Technologies Used

* **HTML5** – For creating the structure and content
* **CSS3** – For styling and layout

## 🎯 Purpose

This project was created to practice and demonstrate my fundamental **HTML and CSS** skills while building a simple personal portfolio website.
